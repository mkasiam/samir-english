================================================================================
CLASS 7 COMPLETE LEARNING PLATFORM - SHARED ARCHITECTURE & DESIGN REFERENCE
================================================================================
Purpose: Provide this file to any developer or LLM when creating independent
subject or chapter HTML pages (e.g., Mathematics, ICT, Science, Bangla) so
that all pages match the platform's visual design, typography, colors,
mobile-first layout, and shared JavaScript APIs without CSS/JS conflicts.

--------------------------------------------------------------------------------
1. FOLDER STRUCTURE & RELATIVE PATHS
--------------------------------------------------------------------------------
CLASS-7-LEARNING/
├── index.html                  (Main homepage)
├── assets/
│   ├── css/style.css           (Shared CSS design system)
│   ├── js/
│   │   ├── subjects.js         (Subject registry: window.CLASS7_SUBJECTS)
│   │   ├── home.js             (Homepage renderer)
│   │   ├── subject.js          (Optional generic content.js renderer)
│   │   └── audio.js            (Shared Web Speech API: window.Class7Audio)
│   └── images/                 (Shared diagrams/images)
└── subjects/
    └── &lt;subject-slug&gt;/
        └── index.html          (Subject entry page; may link to chapter HTMLs)

Relative Path Rules:
- From `subjects/<subject>/index.html`:
  - Homepage: `../../index.html`
  - Shared CSS: `../../assets/css/style.css`
  - Shared Audio JS: `../../assets/js/audio.js`
  - Shared Registry JS: `../../assets/js/subjects.js`
- From `subjects/<subject>/<chapter>/index.html` (nested 1 level deeper):
  - Prefix all shared paths with `../../../` instead of `../../`.
- NEVER use root-absolute paths like `/assets/...` (breaks on GitHub Pages subpaths).

5. SHARED JAVASCRIPT API (window.Class7Audio from assets/js/audio.js)
--------------------------------------------------------------------------------
Do NOT re-implement window.speechSynthesis. Use window.Class7Audio:

1. Class7Audio.speakText(text, lang, callbacks)
   - text: string to speak
   - lang: "en" (uses en-US) or "bn" (uses bn-BD)
   - callbacks (optional): { onStart(), onEnd(), onNotice(msg) }
   - Automatically fires onNotice(msg) if Bangla voice is unavailable.

2. Class7Audio.playSequence(items, callbacks)
   - items: Array of objects, e.g. [{ text: "...", lang: "en", node: el }, ...]
   - callbacks: { onItemStart(index, item), onFinish(), onNotice(msg) }

3. Class7Audio.stop(onStop)
   - Immediately cancels speechSynthesis and resets playback state.

4. Class7Audio.setRate(rate)
   - Sets speech speed (0.5 to 2.0, e.g., 0.75, 1, 1.25).

5. Class7Audio.hasBanglaVoice() -> boolean
6. Class7Audio.isPlaying()      -> boolean
7. Class7Audio.isSupported      -> boolean

--------------------------------------------------------------------------------
6. NON-CONFLICT RULES FOR INDEPENDENT CHAPTER / SUBJECT PAGES
--------------------------------------------------------------------------------
1. Do NOT redefine global styles for `body`, `*`, `.container`, `.btn`,
   `.content-card`, or `.site-header` in inline &lt;style&gt; tags—rely on
   `assets/css/style.css`.
2. If adding custom subject-specific CSS (e.g., an interactive ICT circuit or
   Math graph), prefix custom classes with the subject slug (e.g., `.math-grid`,
   `.ict-table`) so they never collide with shared classes.
3. Ensure zero horizontal scrolling at 320px–375px mobile width. Wrap wide
   tables or equations in `overflow-x: auto`.
4. To register a new subject on the homepage, add one object to
   `window.CLASS7_SUBJECTS` in `assets/js/subjects.js` with:
   { id, name, nameBn, icon, description, path, status, accentColor, bgTint }
   where status is "Available" or "Coming Soon".
